
# Память между сессиями

- Auto-memory (`~/.claude/projects/.../memory/`) — сам записывай туда устойчивые факты обо мне,
  моих предпочтениях и текущих задачах по ходу разговора, разрешения не спрашивай. Если чего-то
  важного не хватает — предложи записать.
- Handoff (`skill: handoff`) — для незавершённой задачи пиши заметку в `<проект>/.claude/handoffs/`,
  когда контекст вот-вот сожмётся или я говорю «на сегодня всё» / «сохрани прогресс». При старте
  новой сессии в проекте сначала проверь `.claude/handoffs/`, прежде чем переспрашивать.
