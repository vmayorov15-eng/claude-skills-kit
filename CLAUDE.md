Бизнес-аналитик по Bitrix24. Основная деятельность:

Подробности обо мне, прайс и кейсы — в `~/.claude/about-me.md`.

# Как со мной работать

- Пиши по-русски, если не попросил иначе.
- Технические решения объясняй простым языком — что это даёт бизнесу/клиенту. Термин можно,
  но с однострочной расшифровкой при первом упоминании.
- Не спрашивай меня про технические детали реализации — решай сам и сообщай, что сделал и почему.
- Спрашивай про бизнес-логику и требования: как должен вести себя процесс, какие поля/статусы
  важны — здесь я источник истины.
- Для UI/бота/интеграции — проверяй сам (браузер, скриншот, лог) и присылай результат с
  доказательством, что работает.
- Если меняешь что-то во внешнем (не тестовом) портале Bitrix24 — сначала уточни.

# Память между сессиями

- Auto-memory (`~/.claude/projects/.../memory/`) — записывай туда устойчивые факты обо мне и
  текущих задачах по ходу разговора, разрешения не спрашивай.
- Handoff (`skill: handoff`) — для незавершённой задачи пиши заметку в `<проект>/.claude/handoffs/`,
  когда контекст вот-вот сожмётся или я говорю «на сегодня всё» / «сохрани прогресс». При старте
  сессии в проекте сначала проверь `.claude/handoffs/`.

# База знаний (Obsidian)

Волт: `~/Obsidian`. Обычные `.md`-файлы — читай и пиши напрямую.

**На чтение.** Если запрос касается клиента — сначала прочитай его карточку в `01 Клиенты` и
связанные `[[ссылки]]`. Карточки нет — проверь `02 Решения`.

**На запись.** Содержательный результат идёт в волт, в чат — короткая сводка и ссылка:
- договорённости и изменения по клиенту → его карточка в `01 Клиенты`
- новое переиспользуемое решение или грабли Bitrix24 → `02 Решения`, со ссылкой на клиента
- итоги встречи → `03 Встречи`
- документы, отчёты, слепки порталов → `04 Документы`
- своё, не клиентское → `06 Мои проекты`

Связывай заметки через `[[Название]]`. Шаблоны — в `Шаблоны`.

# Bitrix24-специфика

- REST API, вебхуки, OAuth, лимиты, ошибки (WRONG_AUTH_TYPE, QUERY_LIMIT_EXCEEDED) → skill `bitrix24-agent`.
- Аналитика, ТЗ, AS-IS/TO-BE, BPMN → skill `bitrix24-analyst`.
- Перед аудитом БП, сменой согласующего, счётчиками, справочниками, формами → skill `b24-grabli`.
- Итоговые документы клиенту → `prd-generator`, `user-story-writer`, `stakeholder-updates`, `docx`/`pptx`.
- Готовое ТЗ → агент `tz-critic`; сдача портала → `config-verifier`; новый клиент → `portal-scout`;
  новый заказ → `lead-estimator`; текст наружу → `text-critic`.
